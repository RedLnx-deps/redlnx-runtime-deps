ONNX Runtime 1.24.2 for Windows x64.

- `onnxruntime-win-x64-gpu-1.24.2.zip`: CUDA package.
- `redlnx-onnxruntime-windows-x64-directml-1.24.2.zip`: DirectML.
- `redlnx-onnxruntime-windows-x64-webgpu-1.24.2.zip`: WebGPU with the Vulkan backend. `webgpu_dawn.dll`, `dxcompiler.dll` and `dxil.dll` stay next to `onnxruntime.dll`.
